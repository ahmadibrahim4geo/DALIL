# المساهمة في DALIL

استخدم الكود الحالي ولا ترفع بيانات المستخدمين أو مفاتيح الخدمات. افتح Issue يوضح الخطوات والنسخة والمتصفح واللغة والسلوك المتوقع والفعل الفعلي، مع عينة مصطنعة صغيرة عند الحاجة.

قبل اقتراح تغيير، شغّل `npm.cmd test` ثم `node test/test_comprehensive_audit.js`. اختبارات المتصفح وGDAL موضحة في `docs/IMPLEMENTATION_STATUS.md`. الاختبار المحلي لا يثبت اكتمال بيانات المصدر أو توافق جميع المتصفحات.

حافظ على X=longitude وY=latitude، ومصدر الحقول، وهندسة Polygon/MultiPolygon والثقوب. افصل مصطلح البحث والمرادف والصفة عن معرّف الفئة الرسمي. أضف الترجمة العربية والإنجليزية لكل نص واجهة جديد. لا تضف مكتبة قبل مراجعة المصدر والترخيص والنسخة وتحديث سجل التبعيات. لا تُضف أي تجاوز لحظر المصدر أو حدوده.

المستودع: https://github.com/ahmadibrahim4geo/DALIL
