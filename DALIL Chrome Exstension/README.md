# دَلِيل | DALIL

**Discovery and Acquisition of Location Information & Listings**

إضافة MV3 عربية افتراضيًا بواجهة إنجليزية مستقلة، لتحديد نطاق دراسة واستكشاف بيانات أماكن مسموح بإعادة استخدامها وتصديرها إلى GIS. تقدم المهام لا يعني اكتمال بيانات الواقع.

## التشغيل

1. افتح chrome://extensions وفعّل وضع المطور.
2. اختر تحميل حزمة مفكوكة، ثم هذا المجلد الذي يحتوي على manifest.json.
3. انقر أيقونة DALIL؛ لا تفتح dashboard كملف ويب عادي.
4. استورد مضلعًا أو طريقًا أو نقطة بإحداثيات WGS84، أو ارسم مستطيلاً/مضلعًا. للطرق والنقاط اضبط مسافة البحث بالمتر، ثم أنشئ الشبكة.
5. اختر الفئات والمصدر ولغة البحث المستقلة عن لغة الواجهة، ثم ابدأ وراجع النتائج والتغطية.

## القدرات المنفذة

تحديث [لغات البحث والرموز R5](docs/LANGUAGES_SYMBOLS_R5.md): نص بحث بأي لغة مع وسم BCP47، ومراجعة مصطلحات الفئات الناقصة دون تحويل صامت للإنجليزية، وحفظ إعدادات اللغة. 1254 هوية رمز محلية بألوان مختلفة وثمانية أشكال، ونفس صور الخريطة مضمّنة داخل KMZ. دعم إدخال اللغة لا يعني ترجمة جميع الفئات أو ضمان تغطية العالم.

استيراد Polygon/MultiPolygon وثقوب، وPoint/MultiPoint وLineString/MultiLineString والملفات المختلطة. للطرق والنقاط شبكة مستطيلة وفلترة قرب بالمتر مع حفظ الهندسة الأصلية. ملكية خلايا حتمية، وحذف/استعادة متسقان، وتراجع في الجلسة. مهام checkpointed مع alarms وإلغاء الردود القديمة وفهرسة المكررات وصفحات نتائج ذات revision. سجل رسمي منفصل لـ513 نوع Google، مع الحفاظ على940 مصطلح بحث ومعرّفاتها وترجمتها؛ القطاعات والفروع تنظيم داخلي. تصدير XLSX وCSV وGeoJSON وJSON وKML وKMZ وShapefile نقطية، ورموز Maki محلية داخل KMZ ومصدر للحقول دون اختلاق بيانات.

## المصادر والقيود

OpenStreetMap عبر Overpass مع [ODbL والنسب](https://www.openstreetmap.org/copyright). حد الخدمة العامة:100 مهمة خلية×استعلام لكل تشغيل و100 طلب يوميًا وفاصل5 ثوانٍ محفوظ عبر الاستئناف. توقف عند رفض المصدر؛ لا تدوير خوادم لتجاوز حدوده. استعمل مستخرجات مرخصة أو موصل خادم خاص بعد مراجعته للاستعمال الكثيف.

Google Maps هو مصدر البحث الافتراضي، ويعمل في تبويب مستقل عن خرائط العرض. المصادر الأخرى اختيارية إضافية. تُحترم إشارات الحظر والتوقف، ولا توجد آليات لتجاوزها. تظل حقوق تخزين بيانات المصدر وتصديرها منفصلة عن تشغيل البحث وعن عرض الخريطة؛ لم يُغيّر هذا التحديث بوابات التصدير الموثقة في سجل التبعيات.

موصل OSM يتحقق من نقاط node ويحتفظ بـway/relation دون نقاط مصطنعة. البحث بلا mapping وسوم موثق يعمل بمطابقة الاسم ويُوسم بذلك. GeoPackage والنموذج الدلالي لم يُفعّلا بعد التقييم. يلزم تقسيم منطقة الدراسة عند خط التاريخ الدولي قبل الشبكة. لا يُدّعى تغطية عالمية كاملة أو GIS GUI roundtrip لم يُنفذ.
