# دَلِيل 2.2.0 — دليل الاستخدام والتطوير

**Discovery and Acquisition of Location Information & Listings**

إضافة Chrome Manifest V3 للبحث عن الأماكن داخل منطقة دراسة، ومراجعة التصنيفات والإحداثيات على الخريطة وفي الجدول، وتصدير السجلات المتاحة لإعادة الاستخدام. الواجهة عربية أو إنجليزية، ولغة البحث مستقلة عنها.

[نبذة المشروع](../README.md) · [سجل التغييرات](../CHANGELOG.md) · [تحديث المكتبة السريعة R6](docs/QUICK_LIBRARY_R6.md)

## التثبيت والتحديث

1. افتح `chrome://extensions` وفعّل **Developer mode**.
2. اختر **Load unpacked** ثم **هذا المجلد**، الذي يحتوي على `manifest.json`.
3. افتح DALIL من أيقونة الإضافة في شريط Chrome.

لا تفتح `dashboard/dashboard.html` كملف عادي، ولا تحتاج إلى تنزيل حزم npm لتشغيل الإضافة. لتحديث نسخة مفكوكة، استبدل ملفاتها ثم اضغط **Reload** في صفحة الإضافات وأعد فتح اللوحة.

## خطوات الاستخدام

1. من **النطاق والشبكة**، ارسم مستطيلًا أو مضلعًا، أو استورد منطقة دراسة بإحداثيات WGS 84. تُدعم النقاط والطرق والمضلعات المتعددة والثقوب؛ للنقاط والطرق حدّد مسافة البحث بالمتر.
2. أنشئ الشبكة وحدّد إعدادات البحث المناسبة.
3. من **الظاهرات والمكتبة**، اختر الطريقة الأنسب:

   | الطريقة | مثال | النتيجة |
   | --- | --- | --- |
   | المكتبة السريعة | مطاعم، مساجد ومصليات، كنائس، شركات، مصانع | هدف عام واحد بمصطلحات قليلة، دون اختيار جميع الفروع الداخلية. |
   | المكتبة التفصيلية | مطعم بيتزا، صيدلية، نوع نشاط محدد | استهداف الأنواع التي تختارها صراحة. |
   | النص الحر | أي عبارة يكتبها المستخدم | بحث بالنص نفسه، حتى لو طابق اسمًا أو معرفًا موجودًا في المكتبة. |

4. حدّد **مصدر البحث ولغته**. Google Maps هو المصدر الافتراضي؛ OpenStreetMap عبر Overpass اختيار إضافي. طبقة الخريطة للعرض مستقلة عن مصدر الأماكن.
5. راجع المصطلحات الناقصة إن ظهرت. يمكنك إدخال مصطلح باللغة المطلوبة أو السماح بالإنجليزية صراحة. خيار العربي والإنجليزي المزدوج لا يفرضهما على اللغات الأخرى.
6. ابدأ المهمة، وتابع حالة كل هدف والخلايا. يمكنك الإيقاف المؤقت والاستئناف، وتُحفظ نقاط التقدم أثناء التشغيل.
7. راجع النتائج والتصنيفات والإحداثيات، ثم اختر صيغة التصدير المتاحة للسجلات.

يمكنك أيضًا إضافة نص حر مباشرة من شريط العناصر المستهدفة في مساحة العمل. يحفظ الحقلان النص واللغة كما أُدخلا، وتستمر الاختيارات بعد إعادة فتح اللوحة.

## ما ستراه في النتائج

- نوع المكان الوارد من المصدر في التصنيف الفرعي، وقطاعه الرئيسي عند معرفته؛ تظل عبارة البحث منفصلة عن نوع المكان.
- رمز مرتبط بنوع المصدر عند التعرف عليه، وعلامة عامة للنوع المجهول. عند غياب النوع قد يُستخدم رمز عبارة البحث مع تنبيه بأنه غير مؤكد من المصدر.
- متابعة **بالانتظار / جاري العمل / مكتمل / انتهى مع نواقص** عند الأهداف. مفتاح الرموز أسفل الخريطة في قسم قابل للطي خارج مساحة التوقيع.
- فصل الإحداثيات الموثقة عن غير المحددة، وحفظ خلية الاكتشاف وخلية ملكية المكان ومعلومات المصدر.

في الإصدار الحالي **38 اختيارًا سريعًا و1075 مفهومًا تفصيليًا**. تشمل المكتبة جميع **478 نوعًا قابلًا للاختيار** من Google Places New حسب مراجعة 14 نوفمبر 2026، مع تسجيل **36 نوعًا للردود**؛ أُظهرت 267 فئة كانت مخفية من الواجهة وأُضيف `town_square`. بقيت 940 ورقة قديمة ومعرفاتها للتوافق والخطط الشاملة. [تقرير المقارنة والمصدر](docs/QUICK_LIBRARY_R6.md#اكتمال-المكتبة-والمصدر).

## صيغ التصدير والإحداثيات

| الصيغة | الاستخدام |
| --- | --- |
| XLSX | جداول Unicode بأعمدة إحداثيات رقمية. |
| CSV | UTF-8 BOM لدعم العربية في Excel. |
| GeoJSON وJSON | هندسة نقطية وخصائص أو سجلات منظمة، مع بيانات المصدر. |
| KML وKMZ | أماكن ورموز؛ تُضمّن صور الرموز المحلية داخل KMZ. |
| Shapefile | حزمة نقطية تضم ملفات الهندسة والسمات وتعريف WGS 84 وترميز UTF-8. |

**X = Longitude = خط الطول، Y = Latitude = دائرة العرض.** تُنسّق الإحداثيات الرقمية بدقة ست منازل عشرية. لا تُحوَّل مراكز الكاميرا أو الخلايا إلى إحداثيات مكان مصطنعة، ولا تُصدَّر السجلات ذات الإحداثيات غير الموثقة كنقاط مكانية.

يخضع التصدير لحقوق المصدر المسجلة. أسماء الأماكن وتصنيفات المصدر الأصلية لا تُترجم عند تغيير لغة الواجهة. راجع [سجل التبعيات وحقوق البيانات](docs/DEPENDENCIES.md).

## المصادر والحدود

Google Maps يعمل في تبويب بحث مستقل، مع احترام إشارات رفض المصدر أو الحظر. لا تعني نهاية البحث اكتشاف جميع الأماكن، ولا يضمن البحث العام الوصول إلى كل نوع فرعي. قائمة Google Business Profile مختلفة عن قائمة Places المنشورة، وتحتاج إلى وصول رسمي حسب البلد واللغة.

OpenStreetMap عبر Overpass يخضع إلى [ODbL والنسب](https://www.openstreetmap.org/copyright). حد الموصل العام الحالي 100 مهمة خلية × استعلام لكل تشغيل، و100 طلب يوميًا، وفاصل خمس ثوانٍ. تتحقق الإضافة من هندسة نقاط OSM؛ تحتفظ بـway/relation دون اختلاق نقطة بديلة. عند غياب ربط وسوم موثق، يُوسم البحث بأنه مطابق للاسم فقط.

تُعرض أول 5000 نقطة على الخريطة لأداء أفضل، مع بقاء السجلات الأخرى في الجدول والتصدير وفق الحقوق. يلزم تقسيم مناطق الدراسة العابرة لخط التاريخ الدولي. GeoPackage والتحليل الدلالي المحلي غير مفعّلين. بعض أسماء الأنواع الإضافية تظهر بالإنجليزية؛ لغة البحث تُحدد بصورة مستقلة أو بمصطلح يدوي.

## الاختبارات

من هذا المجلد، باستخدام Node.js:

```powershell
npm.cmd test
node test/test_comprehensive_audit.js
node tools/project-hygiene.js
```

الأمر الأول يشغّل المجموعة الأساسية لاختبارات المحرك، والاستخراج، والشبكة، والتصدير، والتشخيص. التدقيق الشامل يغطي 30 سيناريو، وأمر فحص التكرار يعمل بالقراءة فقط دون `--apply`.

لتشغيل اختبارات المتصفح، يلزم تثبيت Playwright وChromium في بيئة التطوير. عند استخدام مكتبة خارج المجلد، عيّن `DALIL_PLAYWRIGHT_MODULE` إلى مسارها؛ ويمكن تحديد `PLAYWRIGHT_BROWSERS_PATH` لمكان المتصفح. اختر مجلد أدلة معزولًا:

```powershell
$env:DALIL_BROWSER_EVIDENCE_DIR = Join-Path $env:TEMP 'dalil-browser-evidence'
npm.cmd test
node test/test_search_languages_browser.js
```

تستخدم هذه الاختبارات ملف مستخدم جديدًا وصفحات Google-origin تجريبية مع اعتراض الطلبات الخارجية، ولا تتحكم في جلسة Chrome الشخصية. نجاحها يثبت المسارات المختبرة، ولا يثبت اكتمال Google Maps الحي أو التوافق البصري مع جميع برامج GIS.

لإعادة مقارنة أنواع Google المنشورة عبر اتصال بالإنترنت، دون مفتاح API:

```powershell
node tools/audit-google-place-types.cjs
```

