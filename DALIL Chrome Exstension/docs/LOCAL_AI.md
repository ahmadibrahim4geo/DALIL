# المطابقة المحلية الخفيفة وتقييم النموذج الاختياري

التنفيذ الحالي محرك مصطلحات حتمي محلي، وليس نموذجًا لغويًا. يحتفظ بالنص
الأصلي ويفهرس نسخته المطبّعة فقط: Unicode NFKC، حالة الأحرف، تشكيل العربية
والكشيدة، بعض أشكال الألف والياء، والعلامات اللاتينية المركبة. لا يستبدل
التاء المربوطة بالهاء في فهرس التصنيفات.

مرحلة 1: معرّف/اسم/مرادف مطابق يعيد مفهومًا موحدًا. مرحلة 2: مسافة تحرير
محدودة حرفًا/حرفين تقترح candidates مع score و`requiresReview=true`.
الاقتراح لا يصنف سجلًا تلقائيًا، ولا يدمج منشأتين، ولا ينشئ قيم هاتف/بريد
أو هندسة مكانية. النصوص الملتبسة مثل «زاوية» تستلزم مراجعة بشرية.

| المرشح | المصدر والترخيص الذي روجع | القرار |
| --- | --- | --- |
| فهرس DALIL + مطابقة محدودة | كود مستقل داخل category-registry.js، بلا تبعية | نُفّذ واختُبر؛ كافٍ للمعرّفات والمرادفات المعتمدة وتصحيح أخطاء صغيرة |
| [Fuse.js](https://github.com/krisk/Fuse) | مستودع المصدر وLICENSE: Apache-2.0 | لم يُدمج؛ لا حاجة لمكتبة إضافية لحجم القاموس الحالي، ولا اختُبرت سرعة Fuse ضمن DALIL |
| [Transformers.js](https://github.com/huggingface/transformers.js) | Apache-2.0؛ [توثيق التشغيل داخل المتصفح](https://huggingface.co/docs/transformers.js/en/index) | مرشح مرحلة لاحقة فقط؛ يحتاج مراجعة نموذج/أوزان/WASM منفصلة وقياس تحميل وذاكرة وMV3 فعلي |
| [paraphrase-multilingual-MiniLM-L12-v2](https://huggingface.co/sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2) | بطاقة نموذج المصدر تذكر Apache-2.0 | مرشح دلالي متعدد اللغات، لم تُنزّل أوزانه ولم تُختبر جودة العربية أو سرعته داخل الإضافة |

لا يوجد تحميل نموذج إجباري أو اتصال لخادم ذكاء اصطناعي أو مفاتيح دفع.
تقييم النموذج الدلالي غير مكتمل، ولذلك لم يُعرض كميزة جاهزة. يتطلب اعتماده
تجربة اختيارية بأصول محلية مرخصة، مع تعطيل آمن إذا غاب WebGPU/WASM، ومقارنة
على عينة عالمية بشرية تشمل المرادفات والحالات الغامضة والسجلات المتشابهة.

عينة قياس محلية بعد التنفيذ من `test_taxonomy_registry.js`: 1000 مطابقة
exact استغرقت 1.08 ms، و50 اقتراحًا للكلمة `hospitl` استغرقت 32.84 ms.
هذه عينة Node على جهاز التطوير، ولا تمثل قياس ذاكرة الواجهة أو benchmark
مستعرض أو مقارنة مع Fuse/Transformers. يعيد الاختبار طباعة الأرقام الفعلية
عند تشغيله؛ لا توجد عتبة زمنية هشة تحول بطء جهاز آخر إلى عطل وظيفي.
