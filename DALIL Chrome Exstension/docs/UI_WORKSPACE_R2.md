# مراجعة مساحة العمل والرسم والبحث — 13 نوفمبر 2026

طلب المستخدم: خرائط العرض مستقلة عن مصدر البحث؛ Google هو المصدر الافتراضي، وعملية البحث ظاهرةً عبر كل الخلايا ثم الظاهرة التالية، مع حالة واضحة وشريط تقدم. طلب أيضًا Google Streets/Satellite وEsri Satellite مع مسميات، وتثبيت المشهد، ومنطقة واحدة وحذفًا واحدًا، وإنهاء/إلغاء واضحين للرسم، والتأكد من صيغ الاستيراد، وإصلاح الفراغات وتداخل الحقول وصفحة الأداة والمطور.

## التغييرات

- مصدر Google DOM مفعّل وافتراضي في إعدادات الواجهة والخلفية؛ Overpass خيار إضافي مستقل. لا تتغير خرائط العرض بتغيير مصدر البحث. لا يُتجاوز CAPTCHA أو رفض المصدر، وتظل بيانات الحقوق وسياسات التصدير القائمة مستقلة؛ لم يُضف هذا التحديث إذنًا لإعادة استخدام المحتوى.
- أضيفت core/map-controls.js: Google Streets وGoogle Satellite وEsri Imagery مع World_Boundaries_and_Places، وOpenStreetMap. قائمة Leaflet الأصلية هي قائمة التبديل الوحيدة. زُودت الطبقات بالنسب ولم تُضمّن مكتبة تنفيذية بعيدة أو مخزن بلاطات محلي. روابط Google تستعيد مسار العرض القديم، وليست ادعاء اشتراك في Map Tiles API أو ضمان خدمة أو ترخيص. [Map Tiles API الرسمية](https://developers.google.com/maps/documentation/tile/) مسار مختلف يحتاج إعداد حساب ومفتاح. توثيق [Esri](https://www.esri.com/arcgis-blog/products/arcgis-living-atlas/announcements/sunsetting-legacy-basemaps) يحدد نهاية الخدمة المرجعية القديمة في ديسمبر2029؛ يجب تحديثها قبل ذلك.
- زر «توسيط المنطقة» يعيد العرض للنطاق. حلّ «تثبيت المشهد» محل زر التبديل المكرر. يمنع السحب والعجلة واللمس ولوحة المفاتيح وأزرار التقريب والتحريك التلقائي أثناء المهام، ويصحح تغير المركز عند تغير أبعاد لوحة الخريطة.
- أزيل محدد «النطاق النشط» من الواجهة. الاستيراد والرسم يستبدلان منطقة الدراسة الحالية؛ «حذف المنطقة» يحذف أي حدود حالية والشبكة المحفوظة. حذف النتائج في شريط البيانات يبقى أمرًا مستقلاً. الأوامر القديمة في reducer محفوظة للتوافق، ولا تظهر كأزرار مكررة.
- المستطيل يكتمل بالسحب والإفلات، أو بنقرتين متقابلتين. المضلع يكتمل بزر «إنهاء الرسم» أو النقر المزدوج. يوجد إلغاء وEscape، وإنهاء واضح لتحرير الرؤوس. تُرفض شبكة أثناء مسودة غير منتهية. تُعطّل أوامر المنطقة أثناء التزام الحفظ، ويعيد الإلغاء الرسم السابق. التراجع يرجع هندسة محفوظة، وليس لقطة شكلية فقط.
- حافظ محرك المهام على query-first. أضيف اختبار يثبت الترتيب الفعلي3خلايا×استعلامين في worker harness، واختبار متصفح يشغل background/content الفعليين فوق Google DOM مصطنع2خلايا×استعلامين. روابط الانتقال تتحقق من الاستعلام ومركز العرض بدل افتراض بقاء hash عبر إعادة توجيه Google، ثم تتم مصافحة task identity والتحقق المكاني من كل نتيجة.
- لوحة الحالة في تبويب البحث تعرض الظاهرة وترتيبها، والخلية وترتيبها والصف والعمود، وتقدم المهام المجدولة، وعدد السجلات والمرحلة. تستخدم اتجاهًا مستقلاً للأرقام. تميز بين الفحص المكتمل والجزئي وغير المحسوم والوقف؛ لا تساوي الصفر بعد تصفية مكانية خلوًا مؤكدًا. تُطابق شرائح الظاهرات استعلاماتها المتوسعة، بما فيها الفئات والبحث المزدوج، وتظهر النتائج الجزئية بتحذير.
- أُعيد توزيع حقول المصدر واللغة والرابط في شبكة مضغوطة، وأدوات المنطقة في شريط ملتف، وحددت أبعاد الشعارات. صفحة About لا تحمل شريط تشغيل الخريطة؛ بطاقاتها لها مسافات وعناوين وروابط محددة وتدعم RTL/LTR.

## الاستخدام بعد التحديث

أعد تحميل الإضافة من chrome://extensions، ثم أعد فتح لوحة التحكم. ارسم أو استورد منطقة؛ للرسم المضلع اضغط «إنهاء الرسم». اضبط المشهد واضغط «تثبيت المشهد» قبل بدء المهمة إن أردت إبقاء الكاميرا ثابتة. افتح أيقونة الطبقات داخل الخريطة لتبديل البيز ماب. يظل مصدر البحث Google مستقلًا عن طبقة العرض المختارة.

أوامر التحقق: npm.cmd test، ثم node test/test_comprehensive_audit.js. اختبارات المتصفح الاختيارية عبر npm run test:browser وnpm run test:workspace مع DALIL_PLAYWRIGHT_MODULE وPLAYWRIGHT_BROWSERS_PATH وDALIL_BROWSER_EVIDENCE_DIR وفق بيئة الجهاز. تراجع هذه الوثيقة قرارات الواجهة والمصدر القديمة المتعارضة في IMPLEMENTATION_STATUS.md؛ بقية حدود الإصدار السابق باقية.
