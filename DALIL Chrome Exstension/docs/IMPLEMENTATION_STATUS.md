## الملفات وعلاقاتها

`manifest.json` يحمّل background بوصفه MV3 worker، ويحقن spatial-utils قبل content. الخلفية تستخدم workspace-state للتحولات المحفوظة، وrecords للتطبيع والفهرسة والدمج، وsource-adapters للسياسات والطلبات. يحمل taxonomy-engine سجل category-registry ويحافظ على واجهاته القديمة. يستخدم dashboard المكونات نفسها مع i18n والرموز، وينفذ التصدير في export-worker محلي.

## مقارنة البدائل

راجعنا [QuickOSM](https://github.com/QuickOSM/QuickOSM) (GPL-2.0، تكامل QGIS/Overpass) و[Overpass Turbo](https://github.com/tyrasd/overpass-turbo) (MIT، محرر استعلامات وخرائط وتصدير OSM). استفادت DALIL من فصل وسوم المصدر ولغة العرض وإظهار النسب والتحقق من النطاق. لم ننسخ كودهما، ولم ننفذ benchmark منافسة، ولا ندعي تفوقًا عدديًا. يوفر DALIL واجهة عربية/إنجليزية وإدارة شبكة ومراجعة إحداثيات وتصديرًا متعدد الصيغ في إضافة؛ توفر الأدوات الأخرى كتابة Overpass وهندسات OSM أوسع.

البدائل والتراخيص والإصدارات والأحجام ومبررات الدمج في DEPENDENCIES.md وTAXONOMY.md وLOCAL_AI.md. GeoPackage والنموذج الدلالي مرحلتان مشروطتان قُيّمتا ولم تُفعّلا.

## ما بقي جزئيًا أو غير مختبر

- شبكات عابرة لخط التاريخ الدولي، وهندسة OSM التفصيلية للطرق والعلاقات، والتقسيم التكيفي، وIndexedDB/كتابة نتائج تزايدية تحتاج تنفيذًا لاحقًا. الحفظ الحالي snapshots لكل checkpoint. الخريطة تعرض أول5000 نقطة مع إتاحة بقية النتائج بالجدول والتصدير.
- توافر المصدر الحي وتغطية الدول ودقة كل مرادف وترجمة تحتاج عينات بشرية أوسع. لا تساوي مطابقة الاسم تغطية نوع المكان كله. معرفات Google Business Profile تتطلب وصول API رسميًا لم يُستخدم هنا، وتظل countryAvailability غير المستعلم عنها unknown.
- لم تُختبر واجهات ArcGIS وGoogle Earth Pro وQGIS بصريًا، أو مصفوفة Edge/Brave/Opera/Vivaldi أو screen readers. الاختبارات المستقلة بـGDAL ليست بديلًا عن هذه الاختبارات.
- راجعنا CSP والروابط والأرشيف والموارد ضمن اختبارات التطبيق. فاحص Security Guardian العام الخاص بحزمة المهارات أعاد missing-tool-registry عند توجيهه إلى التطبيق؛ هذا شرط غير منطبق للفاحص، وليس تدقيق ثغرات ناجحًا. OSV/Semgrep/Gitleaks لم تُشغّل.
- لا توجد بيانات Git محلية. أُنشئ baseline ZIP في TEMP بنجاح، لكن عزل TEMP بين الاستدعاءات جعله غير قابل للاسترداد. وقع قطع غير مقصود لذيل dashboard أثناء التطوير، وأُعيد وصل handlers من القراءة السابقة وعولجت أخطاء التشغيل واختُبرت النتيجة. لا يُدّعى diff حرفي للأصل. النسخة المستقرة قبل تنظيف التكرار محفوظة خارج المشروع ببصمة77399568D12C172FE1DE0D571ADC6AB6232271F4E702AB191739B172B0081310.
