# لغات البحث والرموز — R5، 14 نوفمبر 2026

هذه مراجعة تنفيذ فوق المشروع الحالي. الواجهة عربية افتراضيًا وإنجليزية مستقلة؛ اختيار لغة البحث لا يغيّر الواجهة أو أسماء الأماكن الأصلية. لا يلزم ترجمة كل فئة إلى كل لغة حتى يمكن البحث بنص المستخدم.

## ما تغير

- `core/search-languages.js` يقبل وسوم BCP47 الصحيحة بنيويًا، مع قائمة اختيار ومربع لوسم إضافي. النص الحر يحتفظ بلغته ونصه الأصلي، حتى لو طابق مرادف فئة معروفة. يرسل كل استعلام بلغته الخاصة إلى موصل المصدر.
- الفئة ذات المعرّف الثابت تستخدم مصطلحًا موثقًا أو مصطلحًا يحفظه المستخدم لتلك اللغة. الترجمة الناقصة تظهر في مراجعة الخطة وتمنع بدء خطة غير مكتملة. استخدام الإنجليزية بديلًا اختيار صريح، وتُسجل اللغة المطلوبة والمنفذة وسبب الاستبدال. لا تُسقط الأوراق القديمة الـ940 من coverageMap.
- حُفظت اختيارات اللغة والمصطلحات والفئات، وأُصلح حفظ القائمة الفارغة بعد حذف آخر عنصر أو مسح الكل. المصطلح المكتوب يدويًا مستقل عن هوية الفئة الرسمية. لا توجد ترجمة آلية أو نموذج ذكاء اصطناعي محمّل في الخلفية.
- قراءة الأرقام والتقييمات والحقول تراعي تنسيقات لغوية متعددة، وتحفظ النص الخام ولغة صفحة المصدر. القيم المختصرة لا تتحول إلى عدد دقيق مختلق؛ إشارات عدم اكتمال النتائج تبقى صريحة.
- `core/symbology.js` يربط 1254 هوية، تشمل المفاهيم والقطاعات والفروع والرمز غير المصنف، بألوان RGB مختلفة وملفات مختلفة. توجد ثمانية أشكال إطار. المسجد والمصلى يختلفان في الرسم واللون والشكل. الحالات المتقاربة مثل البنك/ATM والطبيب/طبيب الأسنان تستعمل أشكالًا مختلفة أيضًا.
- الصور محلية: 1254 SVG و1254 PNG بدقة64×64، نحو3.3MB إجمالًا، مشتقة من Maki8.2.0 CC0 الموجودة. صور المكتبة تُحمّل بصورة مؤجلة. المصدر الأصلي ذو60 رسمًا محفوظ لإعادة البناء والتوافق؛ ليس نسخًا مطابقة للأصول الجديدة.
- الخريطة وKMZ تستخدمان نفس بايتات PNG. مفتاح تجميع ملفات KMZ هو هوية الرمز، فلا يدمج الفئات المشتركة في الرسم الأساسي. تصدير خصائص `symbol_color`, `symbol_shape`, `symbol_glyph` متاح، مع مقابلات DBF القصيرة في Shapefile.

## المصادر وإعادة البناء

قائمة اختيار اللغات snapshot من [Google Maps JavaScript localization](https://developers.google.com/maps/documentation/javascript/localization#SupportedLanguages)، وتضم82 رمزًا. هذه قائمة API وليست ضمانًا أن Google Maps DOM ينفذ كل وسم `hl` بنفس السلوك. يمكن إدخال وسم إضافي دون ادعاء دعم الخدمة له.

أضيفت105 مصطلحات أساسية من [iD tagging-schema](https://github.com/openstreetmap/id-tagging-schema)،15 نوعًا بسبع نسخ لغوية: الألمانية والفرنسية والإسبانية واليابانية والبرتغالية البرازيلية والصينية المبسطة والتقليدية. المصدر وpreset وGit blob SHA مثبتة لكل مجموعة في الكود، وترخيص ISC في [النص المحلي](TAXONOMY_OSM_LICENSE.md). هذه اقتراحات بحث محلية وليست ترجمة رسمية لفئات Google. راجع [عقد API](SEARCH_LANGUAGES_API.md).

أصول Maki ومصادرها وبصماتها في `assets/symbols/manifest.json`. التعيينات في `category-map.json`، والأصول المشتقة وبصمات PNG في `variants-manifest.json`. أداة `core/symbology-variants.cjs` تبنيها باستخدام Sharp0.35.5 في مضيف التطوير فقط؛ لا Sharp أو كود بعيد أو تبعية تشغيل إضافية في الإضافة.

```powershell
# DALIL_SHARP_MODULE يشير إلى نسخة Sharp المثبتة في بيئة التطوير.
npm.cmd run build:symbols
npm.cmd test
node test/test_comprehensive_audit.js
# يلزم Chromium/Playwright وDALIL_BROWSER_EVIDENCE_DIR منفصل لكل اختبار متصفح.
npm.cmd run test:languages
npm.cmd run test:symbols
```

## الاختبارات وحدود الدليل

اختبارات Node تغطي BCP47، النص الحر دون تغيير، مراجعة النقص، الاستبدال الصريح، بقاء940ورقة، و33حالة أرقام عبر8لغات ومسارات DOM المختلفة. تشمل18سيناريو للـworker الحقيقي داخل harness؛ الرفض قبل البدء لا يغيّر حالة المهمة السابقة. اختبارات الرموز تتحقق من1254لونًا وملف PNG ومفتاح أصل مختلف، ومن الفصل داخل KMZ ومن metadata عبر الصيغ.

اختبار Chromium للرموز يعرض41عينة و328صورة على خلفيات فاتحة وداكنة، ومكتبة AR/EN وعلامات Leaflet وتنزيل KMZ من worker فعلي. القراءة المستقلة للمخرجات باستخدام GDAL3.13.3 وopenpyxl3.1.5 وPillow تتحقق من SHP وGeoJSON وKML وXLSX وPNG داخل KMZ؛ هذه ليست اختبارات واجهة ArcGIS أو QGIS أو Google Earth.

اختبار `test_search_languages_browser.js` نجح داخل Chromium151: سبعة استعلامات حرة FR/ES-AR/DE-DE/ZH-CN/JA/PT-BR/HI، تتبع النص و`hl` لكل طلب، إعادة فتح وحفظ، منع البدء عند نقص المصطلح، حفظ وتنفيذ `boulangerie` يدويًا، والبديل الإنجليزي الصريح مع `hl=en`، ومنع رمز لغة غير صالح دون خطأ تشغيل. مستندات Google-origin في الاختبار fixtures محلية متحكم بها، وليست الخدمة الحية. نجحت أيضًا اختبارات المتصفح السابقة R2/R3/R4 للرسم والتثبيت والاستيراد المكاني وملكية الخلايا وكاميرا المصدر. أظهر فحص التكرار في المشروع الداخلي والخارجي صفر مجموعات مطابقة بايتيًا.

اختلاف RGB والبصمة يثبت غياب النسخة المطابقة؛ لا يثبت أن كل زوج من1254لونًا متباعد بصريًا أو مناسب لكل حالات عمى الألوان. الأشكال والرسوم ومفتاح الخريطة تكمل الألوان. كما أن قبول لغة في الأداة لا يضمن اكتمال ترجمة المكتبة أو توافر البيانات في جميع البلدان. لم تُختبر جميع دول العالم أو كل لغات Google الحية. مصطلحات الفئات غير المترجمة تحتاج مراجعة المستخدم أو البديل الصريح؛ لا توجد ترجمة شاملة مختلقة.
